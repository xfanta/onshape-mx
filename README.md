# Onshape MX Creative

Drive Onshape from a Logitech MX Creative Console — a Logi Options+ plugin plus
the Chrome extension it talks to.

Every toolbar tool is on offer, including the ones Onshape has no keyboard
shortcut for (Chamfer, Shell, Loft, patterns, sheet metal…), and the keypad
follows the toolbar: open a sketch and it switches to sketch tools.

Work in progress.
