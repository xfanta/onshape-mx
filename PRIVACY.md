# Privacy policy

*MX Console Bridge for Onshape* (the Chrome extension in this repository) and the
Onshape plugin for Logi Options+ collect no personal data, and send nothing to the
author or to anyone else.

## What the extension reads

On pages of `onshape.com` only, it reads the structure of Onshape's own interface:

* which buttons the toolbar holds, which are greyed out and which tool is running;
* the name and options of an open feature dialog (for example Extrude's Solid,
  Surface or Thin, or its depth);
* the toolbar's icons.

It does not read your models, documents, file names, account details or anything you
type.

## Where it goes

To the Onshape plugin for Logi Options+ on the same computer, over a connection to
`127.0.0.1` (the computer itself). Nothing leaves the computer. The plugin keeps the
toolbar icons in its own folder so the keys can show them; everything else is held in
memory only while Onshape is open.

There are no analytics, no tracking, no advertising and no remote servers.

## What it does

When you press a key on the MX Creative Console, the extension presses the matching
button in Onshape — a toolbar tool, a dialog option, the dialog's check or cross —
exactly as a click would.
